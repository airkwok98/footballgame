# Three.js 与 Cocos Creator 跨引擎微信小游戏深度迁移评估报告

> **编制**：Game Technical Director / Engine Evaluation Group  
> **评估标的**：`footballgame` (Soccer Pinball 3D)  
> **目标生态**：微信小游戏平台 (WeChat Mini-Game Runtime)  

---

## 1. 评估背景与核心诉求

随着《Soccer Pinball 3D》完成 Visual 2.0 标杆切片（Vertical Slice），项目即将面临未来上线微信小游戏的工程选型抉择：
> **是基于当前成熟轻量的原生 Three.js 体系直接发布微信小游戏，还是整体迁移至 Cocos Creator 3.x 游戏引擎？**

本报告从 **9 大核心维度** 进行严谨的工程与商业化技术对比。

---

## 2. 九大维度横向对比矩阵

| 评估维度 | 原生 Three.js 体系 (当前方案) | Cocos Creator 3.x 引擎方案 | 综合优劣势对比判定 |
| :--- | :--- | :--- | :--- |
| **1. 视觉上限与定制自由度** | ⭐⭐⭐⭐⭐<br>直接操控 GLSL，极易根据项目量身定制轻量 Fake Rim Light 与顶点光带，无引擎冗余封装。 | ⭐⭐⭐⭐<br>具备完整的 PBR 材质编辑器与动画视窗，但自定义 Shader 需遵循其特定的 Effect/Chunk 规范。 | **Three.js 占优**（针对弹珠这种特定受控场景更直接透明）。 |
| **2. 运行时包体与加载速度** | ⭐⭐⭐⭐⭐<br>`three.min.js` 仅 ~600KB，首包加载毫秒级，极契合微信 4MB 首包红线。 | ⭐⭐⭐<br>引擎运行时底座通常需 1.5MB~2.5MB，首包包体预算偏紧，需更精细的分包。 | **Three.js 显著占优**（轻装上阵）。 |
| **3. 微信小游戏生态原生适配** | ⭐⭐⭐⭐<br>通过 `weapp-adapter` 垫片库运行于小游戏容器，社区方案极成熟。 | ⭐⭐⭐⭐⭐<br>具备开箱即用的微信小游戏一键构建、广告 SDK 与排行榜适配支持。 | **Cocos 占优**（商业组件生态成熟）。 |
| **4. 性能表现 (DrawCall/GC)** | ⭐⭐⭐⭐⭐<br>手写轻量渲染循环，零 GC 负担，Draw Calls 严格可控在 60 次以内。 | ⭐⭐⭐⭐<br>引擎通用批处理与渲染管线功能强大，但通用开销略高。 | **平手或 Three.js 略优**。 |
| **5. 资源管线 (GLTF/Audio)** | ⭐⭐⭐⭐<br>标准 GLTF Loader / Web Audio，简单直接。 | ⭐⭐⭐⭐⭐<br>完整的资产导入、纹理压缩（ASTC/KTX2）、模型减面编辑器支持。 | **Cocos 占优**。 |
| **6. 物理与手感迁移成本** | ⭐⭐⭐<br>需将已校准好的自定义物理微步长逻辑重新适配到 Cannon / PhysX。 | ⭐⭐⭐<br>需重写挡杆转动与连续防穿透判定，手感还原需二次调优。 | **当前保留 Three.js 成本最低**。 |
| **7. 迭代效率与调试速度** | ⭐⭐⭐⭐⭐<br>标准浏览器直接跑，本地 `python -m http.server` 秒级刷新即测。 | ⭐⭐⭐<br>需要启动大型编辑器，编译保存有构建等待时间。 | **Three.js 开发反馈更极速**。 |
| **8. AI 辅助开发友好度** | ⭐⭐⭐⭐⭐<br>纯代码与单模块结构对 LLM 代码生成和自审极其友好，极易精准定位。 | ⭐⭐⭐<br>大量的 `.meta` 文件、UUID 与可视化场景绑定，AI 修改可视化 prefab 容易冲突。 | **Three.js 极度适合 AI 协同开发**。 |
| **9. 团队长期维护成本** | ⭐⭐⭐⭐<br>前端 Web 工程师与 Three.js 开发者均可低门槛上手。 | ⭐⭐⭐⭐<br>适合有成熟商业游戏研发背景的客户端团队。 | **持平**。 |

---

## 3. 核心决策结论与实施建议

### 战略结论：**阶段性继续保持 Three.js，暂不全面迁移 Cocos。**

### 阶段建议：
1. **当前阶段（视觉标杆与原型验证）**：
   - 坚决在 **Three.js** 架构下继续打磨 Visual 2.0；
   - 利用其零首包负担、极速代码热更和 AI 协同优势，迅速落地全套材质与手感。
2. **小游戏接入阶段**：
   - 引入成熟的官方开源垫片库（如微信开放平台推荐的 `threejs-miniprogram` 或 `weapp-adapter`）；
   - 将渲染画质档位直接接入微信设备性能查询 API（`wx.getSystemInfoSync`）。
3. **重新评估 Cocos 的触发条件（若未来出现以下任一需求再启动迁移）**：
   - 需要复杂的商用商城/抽奖/战令等数十个可视化 2D 复杂 UI 界面；
   - 需要多平台（微信、抖音、iOS Native、Google Play）同一工程多端发布。
