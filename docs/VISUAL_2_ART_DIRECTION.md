# Visual 2.0 Art Direction (美术与视觉风格规范)

> **制定**：Technical Artist / Game Visual Director  
> **项目**：`footballgame` (Soccer Pinball 3D)  
> **核心艺术定位**：**Premium Night Football Arcade (顶级夜场足球街机)**  

---

## 1. 核心设计哲学 (Design Philosophy)

《Soccer Pinball 3D》在 Visual 2.0 阶段确立唯一定位：
> **保留“顶级欧冠夜场赛事”的纯正足球庄重感，以克制、高阶的街机能量反馈作为点睛之笔，兼具主机级质感与移动端纯净性能。**

我们明确区分两个边界：
- **比 FIFA 更具爽快度与街机击打张力**：拥有水滴机械推杆、Rocket Shot 爆击、冲击波与击球冲拳。
- **比普通弹珠街机更具写实赛场沉浸感**：严禁退化为五彩斑斓的科幻廉价打砖块；草坪、球体、球门物理和球衣必须保持真实足球的厚实质感。

## 2. 核心色彩调色板 (Color Palette)

```
[ Primary Space Dark ]   #050914 / #0b1322  (球场深空与看台夜幕基底)
[ Stadium Pure White ]   #ffffff / #f8fafc  (冷白泛光主球场照明、门柱、球体皮革)
[ Electric Cyan / Azure] #00f0ff / #38bdf8  (赛事科技包装、高能击球导引带、常态能量点缀)
[ Champion Pure Gold ]   #facc15 / #fbbf24  (进球高潮、爆射冲击波、冠军奖杯专属)
[ Controlled Warning ]   #ef4444            (危险落袋预警、极少量关键提示)
```

### 色彩配比红线 (60 : 30 : 10 法则)
- **60% 基底暗色系**：深空蓝黑（`#050914` ~ `#0b1322`），沉着内敛，衬托主体。
- **30% 真实赛场自然色**：精修 PBR 绿茵草坪（`#15803d` ~ `#22c55e`）与高光冷白。
- **10% 受控高能点缀色**：电光青蓝与流金（仅用于挡杆击球导引、Rocket Shot、进球冲击波及关键 HUD）。

## 3. 严格禁止的视觉禁忌 (Strictly Forbidden)

1. ❌ **禁止全屏五颜六色**：除进球庆祝瞬时纸屑外，严禁在常规比赛中出现彩虹粒子或杂乱配色。
2. ❌ **禁止所有对象常态发光**：足球常态必须是真实黑白皮革；挡板常态为半透聚碳酸酯或金属，不准全场泛荧光。
3. ❌ **禁止滥用全屏 Bloom 泛光**：移动端严禁堆叠高能光污染导致画面发白失焦；仅允许在 Rocket Shot 爆射与进球瞬间触发毫秒级受控脉冲。
4. ❌ **禁止频繁文字弹窗遮挡**：取消常规碰撞每次都弹“PASS / BOUNCE / SHOT”等疲劳字样，将反馈还给声音、物理震动与光效。
5. ❌ **禁止过度科幻与赛博朋克**：球场本质是绿茵足球场，绝不能改成霓虹太空打砖块。

## 4. 关键构件视觉标准 (Component Visual Guidelines)

### 4.1 足球 (Ball)
- **常规巡航态**：具备经典黑白皮革拼块质感，微凹凸法线贴图，接受体育场顶棚冷白环境高光映射，**绝不自发光**。
- **Rocket Shot 爆击态**：球体核心泛起金黄微光，边缘呈现锐利菲涅尔金光（Fresnel Glow），身后拖曳平滑变细的矢量光带，脱手瞬间有极短同心冲击环。

### 4.2 挡杆 (Flippers)
- **主体**：曜黑氧化铝合金 / 哑光碳纤维机械构造，彰显现代精工机械感。
- **击球面**：嵌装高摩擦耐磨防滑垫，内嵌微弱青蓝击球准星线，标定 Sweet Spot（甜点区）位置。
- **击打瞬态**：触发弹击时，击球面毫秒级泛白光反馈，动能传导清晰可见。

### 4.3 球员 (Players)
- **形体**：采用人体工学校准后的 Low-Poly 真实球员骨架比例，淘汰立方体拼接人偶。
- **轮廓光 (Rim Light)**：利用自定义轻量 Shader 施加背面冷白微光边缘，使防守队员与门将即使在深色看台背景中也能清晰分辨其站位与跑动方向。
- **分色**：选拔赛第 1 关采用明确的战袍对比（天蓝外场防守 vs 亮橙门将），号码与阴影清晰投射于草坪。

### 4.4 球门与球网 (Goal & Net)
- **门框**：纯白烤漆质感，门柱柱体带有锐利的斜向冷白柱面高光。
- **球网**：通透高强度菱形网格，进球时质点弹簧深度内陷包裹足球，受撞点网格泛起极弱白色应力高光。

### 4.5 镜头语言 (Camera Language)
- **常规比赛**：48° 黄金仰俯角，牢牢锚定比赛核心区域，上下视野兼顾发球区与球门。
- **Sweet Spot 击打**：微量 0.08 单位相机冲量震动（Camera Impulse）。
- **Rocket Shot**：FOV 微幅收缩（48° $\rightarrow$ 46.5°）+ 伴随球体矢量方向轻微回冲，强化推背感。
- **Goal 破门**：进球瞬间 50ms 极短 Hit-Stop $\rightarrow$ 镜头前推聚焦球网深度形变 $\rightarrow$ 曝光脉冲 $\rightarrow$ 平滑回退。

## 5. 微信小游戏性能纪律 (WeChat Mini-Game Discipline)

- **单 Shadow Pass 铁律**：全场仅保留 1 盏主方向光投射阴影，阴影分辨率在移动端限制为 1024 或 2048；
- **Zero-GC 粒子与缓冲池**：光带、冲击波、烟雾与纸花全部采用静态 TypedArray 预分配池，运行期 0 垃圾回收；
- **材质合批与图集**：球员与观众贴图尽可能复用单张材质图集，压减 Draw Calls 至 60 次以内。
